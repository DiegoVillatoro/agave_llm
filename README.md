<h1> Agave Anomaly Detection: Bridging UAV Computer Vision and Agronomic Expertise via Retrieval-Augmented Generation </h1>

<p>Monitoring agave plantations is significantly challenging due to their long growth cycles, environmental heterogeneity, and critical lack of annotated datasets for automated stress detection. This study presents a reference-guided workflow that identifies anomalies by comparing orthomap tiles from UAV with only one healthy reference sample using vision language models. Unlike purely supervised approaches that require extensive labeled data, our system generates spatial heatmaps of potential stress alongside global semantic summaries grounded in expert agronomic knowledge using Retrieval-Augmented Generation (RAG). Preliminary results demonstrate that the pipeline can be repeatable and provides prioritized management recommendations and plausible hypotheses, such as pest activity or nutrient imbalance, for identified hotspots. This methodology offers a scalable and interpretable decisionsupport tool that functions effectively in data-scarce environments, helping agronomists prioritize field scouting and management actions. </p>

<p>The results using multimodal language model for VLM and LLM was effective to evaluate large orthomaps of agave</p>
